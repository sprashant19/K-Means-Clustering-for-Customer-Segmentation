# 🧠 Customer Segmentation using K-Means Clustering

This project demonstrates how to use K-Means Clustering, an unsupervised machine learning algorithm, to segment customers based on their **annual income** and **spending behavior**.

## 📈 Problem Statement
Businesses need to tailor their services and marketing strategies to different types of customers. Using clustering, we can identify customer groups such as:
- High-income, high-spending shoppers
- Budget-conscious consumers
- High-income customers with low spending

## 🛠️ Technologies Used
- Python
- NumPy
- Matplotlib
- scikit-learn

## 🔍 Methodology
- Simulated customer data points (income vs. spending score)
- Applied KMeans clustering (`k=3`)
- Visualized cluster assignments and centroids
- Interpreted results to suggest actionable marketing strategies
